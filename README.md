# 🛜 WiFi Monitor

Система мониторинга и анализа WiFi сетей с веб-дашбордом. Предоставляет информацию о силе сигнала, загрузке каналов, безопасности и историю подключений с рекомендациями по оптимизации.

![Python](https://img.shields.io/badge/Python-3.8+-green)
![Flask](https://img.shields.io/badge/Flask-3.0.0-lightgrey)

## 🌟 Возможности

- **📡 Сканирование WiFi сетей** - автоматическое обнаружение всех доступных беспроводных сетей
- **📊 Визуализация данных** - графики загрузки каналов, распределения по безопасности
- **📶 Мониторинг силы сигнала** - отслеживание качества соединения в реальном времени
- **🔐 Анализ безопасности** - оценка уровня защиты обнаруженных сетей
- **💾 История подключений** - сохранение данных о всех обнаруженных сетях
- **💡 Умные рекомендации** - советы по оптимизации WiFi подключения
- **⚠️ Обнаружение проблем** - автоматическое выявление слабого сигнала, перегруженных каналов
- **🎯 Рекомендация лучшей сети** - выбор оптимальной сети для подключения
- **🔄 Автоматическое обновление** - периодическое сканирование каждые 30 секунд
- **🎨 Современный интерфейс** - красивый темный дашборд с адаптивным дизайном

## 📋 Требования

- Python 3.8 или выше
- Windows / Linux / macOS
- Права администратора для сканирования WiFi (на некоторых системах)

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd wifi-monitor
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск приложения

```bash
python app.py
```

После запуска откройте браузер и перейдите по адресу:
```
http://localhost:5000
```

## 💻 Использование

### Веб-интерфейс

После запуска приложения вы увидите:

1. **Панель статистики** - общее количество сетей, защищенных сетей, средний сигнал, количество проблем
2. **Рекомендации** - советы по оптимизации WiFi подключения
3. **Обнаруженные проблемы** - список выявленных проблем с уровнем серьезности
4. **График загрузки каналов** - визуализация использования каналов в диапазоне 2.4 GHz
5. **График безопасности** - распределение сетей по уровням защиты
6. **Таблица сетей** - полный список обнаруженных сетей с фильтрацией и сортировкой
7. **Рекомендуемая сеть** - лучший вариант для подключения

### Основные функции

- **Кнопка "Сканировать"** - запуск ручного сканирования сетей
- **Поиск** - фильтрация сетей по SSID
- **Сортировка** - упорядочивание по сигналу, имени, каналу или безопасности
- **Автообновление** - данные обновляются автоматически каждые 15 секунд

## 🔧 Конфигурация

Основные настройки в файле `app.py`:

```python
auto_scan_enabled = True       # Включить автоматическое сканирование
auto_scan_interval = 30        # Интервал сканирования (секунды)
```

## 📊 API Endpoints

API доступен для интеграции с другими приложениями:

- `GET /api/scan` - запустить сканирование
- `GET /api/current` - получить текущие данные
- `GET /api/analysis` - получить анализ и рекомендации
- `GET /api/channel-usage` - получить загрузку каналов
- `GET /api/signal-history/<ssid>` - история сигнала для сети
- `GET /api/network-history/<ssid>` - история конкретной сети
- `GET /api/connections` - история подключений
- `GET /api/statistics` - общая статистика
- `GET /api/all-networks` - все обнаруженные сети

### Пример использования API

```python
import requests

# Запуск сканирования
response = requests.get('http://localhost:5000/api/scan')
data = response.json()

# Получение текущих данных
response = requests.get('http://localhost:5000/api/current')
networks = response.json()['data']['networks']

# Получение анализа
response = requests.get('http://localhost:5000/api/analysis')
analysis = response.json()['data']
```

## 🔍 Рекомендации и анализ

Система предоставляет следующие виды рекомендаций:

1. **Оптимизация каналов** - рекомендации по выбору наименее загруженного канала
2. **Безопасность** - предупреждения о небезопасных сетях
3. **Улучшение сигнала** - советы при слабом сигнале
4. **Общие рекомендации** - использование непересекающихся каналов (1, 6, 11)

### Типы проблем

- **Перегруженность каналов** - слишком много сетей на одном канале
- **Небезопасные сети** - открытые или слабо защищенные сети
- **Слабый сигнал** - низкое качество подключения

## 🛠️ Устранение неполадок

### Windows

Если сканирование не работает, запустите командную строку от имени администратора:

```bash
python app.py
```

### Linux

Убедитесь, что установлен NetworkManager:

```bash
sudo apt-get install network-manager
```

### macOS

Может потребоваться разрешение на доступ к WiFi в настройках конфиденциальности.

## 🔐 Безопасность

- Приложение НЕ подключается к сетям автоматически
- Пароли WiFi НЕ хранятся и НЕ обрабатываются
- Все данные хранятся локально в файле `wifi_data.json`
- Веб-интерфейс доступен только локально (localhost)
